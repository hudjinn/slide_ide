    Comparação: Sublime Text vs VS Code

    Critério Sublime Text VS Code
    Velocidade Extremamente leve e rápido Razoavelmente rápido, mas mais pesado
    Funcionalidades integradas Editor básico, precisa de plugins Completo: terminal, Git, debug etc.
    Consumo de recursos Baixíssimo Mais alto (usa Electron)
    Customização Alta, via arquivos JSON Alta, via interface e JSON
    Extensões Boa variedade (via Package Control) Enorme marketplace de extensões
    Git integrado Não nativamente (precisa de plugin) Sim, com interface visual nativa
    Licença Paga (com avaliação sem limite de tempo) Gratuito e open source
    Ideal para Usuários que priorizam leveza e velocidade Desenvolvedores que querem tudo integrado
